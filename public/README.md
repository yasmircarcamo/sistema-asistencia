# Sistema de Control de Asistencia de Personal

Sistema web ligero para la gestión de asistencias, catálogo de empleados, chequeo y generación de reportes.

## Tecnologías Utilizadas
- **Backend:** Node.js, Express, SQLite (`better-sqlite3`)
- **Frontend:** HTML5, Tailwind CSS, JavaScript ES6, Chart.js
